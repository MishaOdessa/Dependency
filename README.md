# apkgraph

Инструмент визуализации графа зависимостей пакетов Alpine Linux (apk).
Зависимости получаются без менеджеров пакетов и сторонних библиотек.

Сейчас реализован этап 1: CLI с настраиваемыми параметрами.

## Параметры

| Опция | Описание | Обязательна |
|---|---|---|
| `--package` | имя анализируемого пакета | да |
| `--repo` | URL репозитория или путь к файлу тестового репозитория | да |
| `--test-mode` | считать `--repo` путём к файлу тестового графа | нет |
| `--version` | версия пакета | да |
| `--output` | имя файла с изображением графа (по умолчанию `graph.svg`) | нет |
| `--ascii-tree` | вывести зависимости в виде ASCII-дерева | нет |
| `--filter` | пропускать пакеты, в имени которых есть эта подстрока | нет |

Справка: `python src/main.py --help`

## Обработка ошибок

Программа завершается с понятным сообщением и кодом 1, если:
пустое имя пакета или версия; `--output` не заканчивается на `.svg`;
`--repo` не является http(s) URL; в тестовом режиме файл не найден.
Отсутствие обязательной опции или неизвестная опция даёт код 2.

## Запуск

```
python src/main.py --package nginx \
    --repo https://dl-cdn.alpinelinux.org/alpine/v3.19/main \
    --version 1.24.0
```

## Демонстрация и проверка

```
bash tests/demo.sh
```

Скрипт запускает программу с одним правильным набором параметров,
затем со всеми ошибочными вариантами по очереди.
